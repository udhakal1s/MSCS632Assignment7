## How to run C
## Tools I Used
- WSL Ubuntu Terminal
- GCC (build-essential)

## How to Run
- First, clone the repo and go to the folder with the C source file
- sudo apt update
- sudo apt install -y build-essential
- gcc -Wall -Wextra -O2 -o MSCS632A7C MSCS632A7C.c
- ./MSCS632A7C

## How to run OCaml
## Tools I Used
- WSL Ubuntu Terminal
- OCaml (ocamlc)

## How to Run
- Clone the repo and go to the folder with the OCaml source file
- sudo apt update
- sudo apt install -y ocaml
- ocamlc -o MSCS632A7Oc MSCS632A7Oc.ml
